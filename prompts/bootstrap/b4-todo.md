# Bootstrap 4 — the plan file

Run at the start, in a copy of the repo with the template moved aside:

    mv TODO.template.md TODO.shipped.md

---

You are about to run a multi-phase evaluation against a remote endpoint that
drops out regularly, and you will need to survive losing your context window at
least once.

Before doing any of the work, design the plan file you want to keep this on
track. Write it as TODO.md.

Think about what a version of you that had lost all memory of this conversation
would need in order to resume: not just which steps remain, but enough state to
know where the last one stopped.

Then diff it against TODO.shipped.md and tell me which is better and why.
