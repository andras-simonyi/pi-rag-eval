# Prompt 03 — sweep and score (20 min)

Purpose: the agent should recognise this phase as mechanical and reach for the
script. If it starts making individual calls, that is a teachable failure —
let it run three or four, then interrupt and ask why.

---

Run the configuration sweep and score the results.

Note the wall-clock time the sweep takes and include it in your report later.
If the endpoint drops mid-sweep, tell me rather than retrying forever.
